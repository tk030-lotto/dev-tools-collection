# 作りっぱなし対策ツール集

Markdownリンク検査、GitHub公開前点検、引き継ぎパック生成、プロンプト差分、文書整合性チェックの5機能を備えた、ブラウザ完結型の開発支援ツール集です。

**公開 URL**: https://tk030-lotto.github.io/dev-tools-collection/

## できること

1. **Markdown Link Checker（リンク・画像パス検証）**
   - Markdown ファイル内の相対パスリンク、画像参照パス（`![alt](path)`）、ページ内見出しアンカー（`#heading`）、外部 URL の構文を検査し、リンク切れ箇所を一覧表示します。
2. **GitHub Preflight（公開前セルフチェック）**
   - リポジトリを公開する前に、API キーやトークン等の機密情報パターン、`.env` や `node_modules` 等の不要ファイル、大容量ファイル、未解決のデバッグコード（`console.log`, `debugger`, `TODO`）を点検します。
3. **Handoff Pack（引き継ぎプロンプト・ドキュメント生成）**
   - 作業の目的・完了項目・残課題・関連ファイルを入力し、AI エージェントやチームメンバーへの引き継ぎ用 Markdown ドキュメントを3種類のテンプレート（Standard / Minimal / Full Context）から生成します。
4. **Prompt Diff（プロンプト・テキスト差分比較）**
   - 2つのプロンプトや設定ファイルの差分を行単位・単語単位で比較し、Side-by-Side（左右並列）または Unified（統合）形式で可視化します。前後の空白無視や単語ハイライトの切り替えに対応しています。
5. **Document Consistency Checker（ドキュメント整合性・表記ゆれ検査）**
   - 複数の Markdown ドキュメントを横断して、用語の表記ゆれ、文書間のタスク進捗ステータスの矛盾、標準セクションの欠落、未完了の TODO やチェックリスト項目を検出します。
6. **レポート出力**
   - 各ツールの検査結果や生成文書を、Markdown (`.md`)、HTML (`.html`)、JSON (`.json`)、テキスト (`.txt`) 形式で保存、またはクリップボードへコピーできます。

## 使い方

1. https://tk030-lotto.github.io/dev-tools-collection/ を開きます。
2. ダッシュボードまたは上部タブ・左サイドバーから使用するツールを選択します。
3. 検査対象のファイルまたはフォルダをドラッグ＆ドロップするか、テキストを入力して結果を確認・保存します。

## 外部通信

- すべてのファイル読み込み・解析・生成処理はお使いのブラウザ内（ローカルメモリ上）で実行されます。
- 選択したファイルや入力したテキストが外部サーバーへ送信されることはありません。外部フォントや外部 CDN への通信も行いません。

## 動作環境

- Google Chrome / Microsoft Edge / Safari / Firefox の最新版（PC・スマートフォン対応）

## 制限・注意

- 本ツールの検査は、定義された規則およびパターンに基づく補助的なものです。機密情報の検出漏れや外部URLへの接続確認は行いません（外部URLは構文のみを検査します）。
- スマートフォンの実機での表示は確認できていません。
- GitHub Preflight の本文検査は、5MB 以下のファイルに対応しています。
