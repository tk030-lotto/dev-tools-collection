# HandoffPack (AIプロジェクト引き継ぎパック生成ツール)

AIや開発者へプロジェクトを引き継ぐ際に必要なドキュメントを自動収集し、引き継ぎパックを生成するローカル環境向けツールです。

---

## 1. 開発目的

AIを活用した開発では、チャットの切り替えやAIの変更、共同開発などにより、プロジェクト情報を何度も引き継ぐ必要があります。

しかし、必要なドキュメントを毎回手作業で収集・整理するのは手間がかかり、渡し漏れや情報不足が発生しやすくなります。

本ツールは、プロジェクト内の必要な情報を自動収集し、AIや開発者へ渡すための引き継ぎパックを生成することを目的とします。

---

## 2. 主な機能（MVP）

* 指定フォルダの解析
* Markdownファイルの収集
* 引き継ぎ対象ファイルの選択
* 引き継ぎパックの生成
* Markdown形式で出力

---

## 3. 入力

* プロジェクトフォルダ
* Markdownファイル
* テキストファイル

---

## 4. 出力

* 引き継ぎパック（Markdown）
* 収集対象一覧
* 生成結果レポート

---

## 5. 動作仕様

1. プロジェクトフォルダを選択
2. 対象ファイルを検索
3. 引き継ぎ対象を収集
4. 引き継ぎパックを生成
5. Markdownファイルとして保存

---

## 6. 制限事項（MVP）

* ローカルフォルダのみ対応
* Markdown・テキストファイルのみ対象
* ZIP圧縮機能は対象外
